# Commercial Strategy

A pilot would test whether a specific buyer can make a better decision using PoWV evidence. The following options are proposals for discussion with a partner.

| Candidate partner | Decision to test | Observable pilot result |
| --- | --- | --- |
| Agricultural warehouse or industrial operator | Accept a delivery record or investigate a discrepancy between the instrument and the ERP. | Time to reconcile a lot and share of discrepancies resolved against the source record. |
| Industrial security or treasury team | Authorize or hold a simulated operation based on evidence about its originating environment. | Correct decisions on agreed test cases, false holds and review time. |
| Trade-finance or RWA platform | Accept supporting evidence for a warehouse record into the institution's review process. | Time to assemble a reviewable file and number of missing or conflicting records. |
| Recycling or recovery operator | Reconcile recovered material with the facility's intake records. | Time spent resolving discrepancies and share of loads with traceable evidence. |

The weighing bench provides a starting point for an acquisition pilot. Other trials require their own implementation and readiness checks. A partner agreement would identify the workflow owner, baseline, deliverable, acceptance criteria and price.
